# SalonnIOS

A mobile application for salon services and bookings.

## Description

SalonnIOS is an iOS application that allows users to browse, book, and manage salon appointments.

## Features

- User authentication
- Browse salon services
- Book appointments
- Manage profile and bookings
- Notifications for booking updates

## Requirements

- iOS 15.0+
- Xcode 14.0+
- Swift 5.0+
